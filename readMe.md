# 📚 Bases da Programação — Lógica e Algoritmos em C

Este repositório foi criado para armazenar os exercícios e códigos desenvolvidos durante as aulas da matéria de **Bases da Programação**. O objetivo principal destes programas é exercitar a **lógica de programação**, compreendendo na prática o funcionamento dos algoritmos, o fluxo de execução e a manipulação de estruturas de repetição (`for`).

---

## 🎯 Objetivos de Aprendizado

- Compreender a estrutura de repetição `for` e seus componentes (inicialização, condição e incremento/decremento).
- Praticar a lógica de controle de fluxo e manipulação de variáveis.
- Explorar cenários avançados de laços, como múltiplas variáveis de controle simultâneas e alterações multiplicativas.
- Desenvolver autonomia na escrita e depuração de código em C.

---

## 📁 Arquivos do Repositório

Abaixo está a lista de exercícios práticos salvos no repositório com suas respectivas abordagens de lógica:

| Arquivo | Conceitos de Lógica Aplicados |
| :--- | :--- |
| **`forPrintf.c`** | **Estrutura básica de laço:** Laço `for` simples com contagem progressiva de 1 a 10 e impressão formatada. |
| **`pares.c`** | **Filtro e Acumulador:** Identificação de números pares no intervalo de 0 a 10 e contagem acumulada do total de elementos. |
| **`somaSubtrai.c`** | **Variáveis concorrentes:** Uso de duas variáveis no mesmo `for` (uma incrementando e outra decrementando simultaneamente). |
| **`multiplicacao.c`** | **Progressão não-linear:** Alteração da variável de controle do laço usando multiplicação por valor negativo a cada passo. |
| **`doisParametros.c`** | **Múltiplas instruções:** Atualização avançada de parâmetros no cabeçalho do laço e manipulação matemática na saída. |

## 🛠️ Como Compilar e Executar os Exercícios

Para testar qualquer um dos códigos, você precisará de um compilador C instalado no seu computador (como o **GCC**).

### 1. Clonar o Repositório
```bash
git clone https://github.com/seu-usuario/bases-da-programacao.git
cd bases-da-programacao
```

### 2. Compilar e Executar no Terminal

Substitua `nome_do_arquivo.c` pelo arquivo que deseja rodar:

* **Linux / macOS:**
  ```bash
  gcc nome_do_arquivo.c -o programa
  ./programa
  ```

* **Windows (CMD / PowerShell):**
  ```cmd
  gcc nome_do_arquivo.c -o programa.exe
  .\programa.exe
  ```
